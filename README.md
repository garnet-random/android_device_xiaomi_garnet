# Xiaomi Redmi Note 13 Pro 5G (garnet)

The **Xiaomi Redmi Note 13 Pro 5G / Poco X6 5G** (codenamed _garnet_) is a mid-range smartphone from Xiaomi, released in September 2023.

## Device Specifications

| Feature | Specification |
| :--- | :--- |
| **SoC** | Qualcomm Snapdragon 7s Gen 2 (SM7435) |
| **CPU** | Octa-core (4x2.40 GHz Cortex-A78 & 4x1.95 GHz Cortex-A55) |
| **GPU** | Adreno 710 |
| **Memory** | 8 GB / 12 GB |
| **Storage** | 256 GB / 512 GB UFS 2.2 |
| **Battery** | Non-removable Li-Po 5100 mAh |
| **Charging** | 67W wired PD3.0 |
| **Display** | 6.67" AMOLED, 120Hz, Dolby Vision, 1220 x 2712 pixels |
| **Rear Camera** | 200 / 64 MP (wide) + 8 MP (ultrawide) + 2 MP (macro) |
| **Front Camera** | 16 MP (wide) |
| **Dimensions** | 161.2 x 74.2 x 8 mm |
| **Weight** | 187 g |
